# CODSOFT Internship Tasks

This repository contains the machine learning and artificial intelligence projects completed during my CODSOFT internship.

## 👨‍💻 Internship Projects

### Task 1 — Movie Genre Classification

A machine learning project that predicts the genre of a movie from its plot description.

**Techniques Used:**
- Natural Language Processing (NLP)
- TF-IDF Vectorization
- Logistic Regression
- Linear Support Vector Machine (SVM)
- Multinomial Naive Bayes
- Model Evaluation
- Confusion Matrix

**Best Model:** Logistic Regression

---

### Task 2 — Credit Card Fraud Detection

A machine learning project that identifies potentially fraudulent credit card transactions.

**Techniques Used:**
- Data preprocessing
- Feature engineering
- Handling numerical and categorical features
- One-Hot Encoding
- Standardization
- Logistic Regression
- Random Forest
- Model evaluation

---

### Task 3 — Spam SMS Detection

A text classification project that classifies SMS messages as either spam or legitimate.

**Techniques Used:**
- Natural Language Processing (NLP)
- Text preprocessing
- TF-IDF Vectorization
- Naive Bayes
- Logistic Regression
- Support Vector Machine (SVM)
- Accuracy, Precision, Recall and F1 Score
- Confusion Matrix
